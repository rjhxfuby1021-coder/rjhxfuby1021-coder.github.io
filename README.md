# texspeckps.ru — сайт Павла Корчагина

Статический сайт на GitHub Pages. Любое изменение в ветке `main` автоматически
пересобирается (`node build.js`) и публикуется — см. вкладку **Actions**.

- `src/` — исходники: общие стили и скрипты, страницы, данные кейсов (`src/data/cases.json`)
- `static/img/` — картинки сайта (адрес на сайте: `/img/имя-файла`)
- `build.js` — сборка: `site/` (сайт), `АДМИНКА.html` (админка кейсов)
- `tools/` — вспомогательные скрипты (скачивание и сжатие картинок)

## Добавить кейс

1. Откройте `АДМИНКА.html` на компьютере, создайте кейс, нажмите «Скачать cases.json».
2. Картинки загрузите в папку `static/img/` (Add file → Upload files) и укажите в админке как `/img/имя.webp`.
3. Загрузите `cases.json` в папку `src/data/` с заменой (Add file → Upload files → Commit).
4. Через минуту сайт обновится.
