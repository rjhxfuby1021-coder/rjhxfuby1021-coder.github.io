# texspeckps.ru — установка в Tilda и SEO

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `УСТАНОВКА.html` | **Помощник установки** — кнопки «Блок 1, 2…» для каждой страницы и SEO-тексты |
| `dist/blocks/*.html` | Те же блоки файлами: `tilda-1.html`, `tilda-2.html`… |
| `dist/*.html` | Страница целиком (для просмотра на компьютере, в Tilda не вставлять) |
| `admin/admin.html` | Локальная админка кейсов (открывать двойным кликом) |
| `src/` | Исходники: общие стили и скрипты, страницы, данные кейсов |
| `build.js` | Сборка: `node build.js` → обновляет `dist/` и `admin/admin-kit.js` |

`tilda-block.html` в корне — первая версия главной, её заменяет `dist/index.html`.

## Установка каждой страницы

1. Tilda → нужная страница → удалить старые блоки.
2. Tilda ограничивает размер блока, поэтому каждая страница — **2–5 блоков T123 подряд**
   (сколько — видно в УСТАНОВКА.html). Добавить нужное количество блоков T123 один под другим.
3. В 1-й блок вставить «Блок 1», во 2-й — «Блок 2» и т. д. **Порядок важен.**
4. Настройки сайта → «Шапка и подвал»: общую шапку/подвал Tilda отключить — у каждой страницы свои.
5. Настройки страницы → SEO и «Соцсети» — тексты из таблицы ниже.
6. Опубликовать.

Блоки каждой страницы — в `УСТАНОВКА.html` или файлами `dist/blocks/<страница>-<номер>.html`
(главная — `index-1…3`, кейсы Tilda — `tilda-1…5` и т. д.).

## Что уже сделано в коде

- Один H1 на странице, H2 у каждой секции, семантические `header / nav / main / section / footer`.
- Весь русский текст — в HTML (виден поисковикам), английский подставляется скриптом.
- Микроразметка Schema.org: `Person` и `ProfessionalService` (главная), `CollectionPage` +
  `CreativeWork` (кейсы), `OfferCatalog` (цены), `FAQPage` (вопросы), `ProfilePage` (обо мне,
  резюме), `Review` (отзывы).
- У каждого кейса своя ссылка: `/tilda#maxfit`, `/salebot#sb-jador` и т. д.
- Адаптив 375–1440 px, тёмная и светлая темы, `prefers-reduced-motion`, навигация с клавиатуры.

## Как добавить новый кейс

1. Загрузите скриншоты в Tilda (любой блок «Изображение» на скрытой странице) и скопируйте ссылки.
2. Откройте `admin/admin.html` → «+ Новый кейс» → заполните поля (справа — живой предпросмотр).
3. «Код страницы /<направление>» → появятся кнопки «Блок 1, 2…» → вставьте их по порядку в блоки T123
   этой страницы. Если блоков стало больше, чем было, — добавьте на странице ещё T123.
   Затем то же для `/keys` (там счётчики и превью).
4. «Скачать cases.json» → положите файл в `src/data/`, чтобы следующая сборка `node build.js`
   тоже знала о новом кейсе.
