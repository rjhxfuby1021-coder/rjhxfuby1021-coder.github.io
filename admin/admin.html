Как получить ключ (один раз)
  1. Откройте github.com → новый ключ.
  2. Token name: Админка сайта, Expiration: 1 год.
  3. Repository access → Only select repositories → rjhxfuby1021-coder.github.io.
  4. Permissions → Repository permissions: Contents — Read and write, Actions — Read-only.
  5. Generate token → скопируйте ключ → вставьте выше → «Подключить». Браузер предложит сохранить — соглашайтесь.
