Установка сайта в Tilda

Идите по карточкам сверху вниз. Tilda ограничивает размер одного блока, поэтому каждая страница разбита на несколько блоков T123 подряд. Отмечайте готовые страницы — отметки сохраняются.

Один раз перед началом

  1. Сделайте копию проекта: Tilda → «Мои сайты» → у проекта «…» → «Дублировать». Если что-то пойдёт не так — старый сайт останется.
  2. В проекте откройте «Настройки сайта» → «Шапка и подвал» и выберите «Без шапки» и «Без подвала» — у каждой новой страницы они свои.
  3. Проверьте, что адреса страниц совпадают со списком ниже: «Настройки страницы» → «Адрес страницы».

Для каждой страницы (13 раз)

  1. Откройте страницу в редакторе Tilda и удалите все старые блоки (наведите на блок → корзина).
  2. Добавьте столько блоков T123 «HTML-код», сколько у страницы кнопок «Блок» («+» → «Другое» → T123), один под другим.
  3. Здесь нажмите «Блок 1» → в Tilda у первого T123: «Контент» → кликните в поле → Ctrl+V → «Сохранить и закрыть».
  4. Затем «Блок 2» → во второй T123, и так далее. Порядок важен: блоки должны стоять на странице ровно в этом порядке сверху вниз.
  5. «Настройки страницы» → SEO и «Соцсети»: вставьте заголовок и описание (кнопки «копировать» рядом).
  6. «Опубликовать» → откройте страницу по ссылке и проверьте. В редакторе блок выглядит как серая заглушка — это нормально.
