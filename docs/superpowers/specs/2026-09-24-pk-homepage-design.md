## Переключатели темы и языка

Оба — в шапке (на мобильных — внутри бургер-меню и компактно в шапке).

**Тема «Тёмная / Светлая»:**
- По умолчанию тёмная (бренд). Выбор запоминается в `localStorage` (`pk-theme`),
  чтение/запись в try/catch.
- Все цвета — CSS-переменные на `.pk-root`; светлая тема переопределяет их через
  `.pk-root[data-theme="light"]`. Смена темы — плавный переход цветов (без
  анимации при reduced-motion).
- Кнопка — `<button aria-pressed>` с иконками солнца/луны.

**Язык «RU / EN»:**
- По умолчанию RU. Выбор запоминается в `localStorage` (`pk-lang`).
- Русский текст лежит в HTML (индексируется). Английский — словарь в JS; элементы
  с `data-i18n="ключ"` подменяют текст, `data-i18n-attr` — атрибуты (aria-label,
  alt). Меняется и `lang` у `.pk-root`.
- Внутренние страницы только на русском: в EN-режиме у ссылок на них пометка «RU».
- Переключатель — сегмент-кнопка `RU | EN` с `aria-pressed`.
- SEO: индексируется русская версия; EN — удобство для посетителей.

## Анимация

- Появление блоков при скролле (IntersectionObserver, класс `is-in`).
- Счётчики считают от 0 при попадании в экран.
- Орбита чипов вокруг фото (CSS), мягкое свечение фона.
- Переворот карточек болей (CSS 3D), схема воронки — `stroke-dashoffset` по скроллу.
- Магнитные кнопки на десктопе (только pointer: fine).
- `prefers-reduced-motion: reduce` отключает всё движение, контент виден сразу.
